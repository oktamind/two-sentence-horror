A program that writes an original two-sentence horror story: a favorite photo of mother holding "me" as a baby, taped to the fridge — dated two years before the narrator was born. Sentence one is calm and ordinary; sentence two reframes it, and the horror is left implied.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
